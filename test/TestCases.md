# SkillSwap

"Knowledge increases by sharing but not by saving."

SkillSwap is a web-based platform that allows users to exchange skills and knowledge with others. Users can create profiles, search for skills, communicate with other users, schedule learning sessions, and provide feedback after completing skill exchanges.

## Installation

1. Clone or download the project.
2. Move the project folder to:

text
C:/xampp/htdocs/skillswap


3. Create a database named:

text
skillswap


4. Import:

text
skillswap.sql


5. Start Apache and MySQL in XAMPP.
6. Open:

text
http://localhost/skillswap
